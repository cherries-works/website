Low-Level by choice

We work with Low-Level languages, to be able to control all the usage down to the metal. So we can optimize the code as best as we can.

No bloat

No outside libraries used, and everything compiles down to a single binary.

Open Source

All our projects are 100% open-source. Trust is built in the open.

Runs anywhere

From beefy servers to Raspberry Pi. If it has a CPU, it can run our tools.

Vision

Programs that make your fans stop spinning, so even foxes can sleep nearby.

Our goal is to design tools that everyone can run anywhere, without having to worry about their specs. If your PC has a CPU, and any stick of RAM, it should be able to run cherries.works tools.

The requirements for a program to run are getting larger and larger. Computational power is rising, however optimization is not rising with it.

Open Source

Developers have the right to see what they are running. cherries.works embraces that philosophy.

All of our tools are open-source by default (even our website), because we want people to see what we are building. We have nothing to hide.

Furthermore, we encourage users to check out and read through our source code, it is an honor.

cherries.works Pulse has 5+ outside contributions, and currently more than 30+ stars! Every kind of support is more than welcome.

Our Future

We do not plan on releasing new projects every day, maintaining multiple repos, and handling cloud infrastructure all at once.

cherries.works starts small. One project is currently our main focus; Pulse.

That however does not mean that it will always be the case. We are working in the background, to see what could be useful to developers.
