Vision

More and more software projects start eating away your RAM, and your CPU.
The problem with a lot of new software is, that it tries to do everything without thinking about places for optimization. Also, because most of these projects are closed-software, you don't really know what you're running.

cherries.works tries to change that.

We try to create software that is excellent at one thing.

Currently, we are working on;

  • Pulse - A system monitoring and observability tool.
  • Deploy - Simplified deployment tool.

But in the future we hope to expand to more areas, where developers need better, optimized, simplified and open-source software such as;

  • Edge and embedded systems
  • Storage and data processing utilities
  • Performance analysis and debugging

However, that is for the future.

Up until then, we will try to keep our philosophy, that being;
Tools that are scaleable.
That are resource-efficient.
Maintainable.
Easy to install and run.
And open source.

Every dev has a right to understand and read the code of the tool that they are working on.

The future of cherries.works is not a single product.
It is a growing collection of tools that help developers build maintainable systems with less complexity, better efficiency, and greater control.
